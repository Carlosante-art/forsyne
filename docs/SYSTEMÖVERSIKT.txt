3. KRYPTERING
═══════════════════════════════════════════════════════

  Algoritm: AES-256 via CryptoJS
  Nyckel:   ENCRYPTION_KEY i miljövariabler

  Krypterade fält:
    profiles.data.q1_1       — varför användaren är här
    profiles.data.q2_11      — vad som förändrade dem
    checkins.reflection       — daglig reflektion (fritext)
    checkins.personal_answer  — svar på personlig fråga (fritext)

  Server krypterar vid skrivning, dekrypterar vid läsning.
  Supabase lagrar alltid krypterad ciphertext.


═══════════════════════════════════════════════════════
4. PSI — PERSONAL STATUS INDEX
═══════════════════════════════════════════════════════

  Formel:
    PSI = ((energi + sömn + (10 - stress) + fokus + motivation) / 5) × 10

  Skala: 0-100
  Tolkning:
    PSI > 70   — grön, kör planerat träningspass
    PSI 55-70  — gul, sänk intensitet 1-2 enheter
    PSI < 55   — röd, kör aldrig tungt planerat pass

  Beräknas:
    - Server-side i meta-agenten (psiOf-funktion)
    - Schema-agenten (per dag och för idag)
    - Klient-side (dashboard.html, checkin.html)

META-AGENTEN (prompts/meta_agent.md)
──────────────────────────────────────────────────────
  Trigger:   POST /api/agent/meta/run
             POST /api/agent/meta/schedule (intern, daglig)
  Uppgift:   Systemets kärna. Ser hela bilden. Uppdaterar
             användarmodellen. Sparar systeminsikt.
  max_tokens: 8 000
  Cache:     6 timmar (körs ej igen om nyare insikt finns)
  Retry:     3 försök vid overloaded, 10s paus

  Input till Claude (payload):
    analys_period         — datum + antal dagar
    profil                — decrypterad profildata
    checkins              — alla check-ins som textrader
    kritiska_dagar        — dagar med stress≥7 / sömn≤4 / energi≤2
    period_snitt          — snitt per 7-dagarsperiod
    tidigare_insikter     — senaste 30 insikter
    valideringssvar       — feedback från validerings-agent
    dagar_aktiv           — antal dagar i systemet
    personliga_baslinjer  ← NY: snitt+std per metrik
    korrelationer         ← NY: top 8 laggade Pearson-korrelationer (r≥0.4, n≥8)
    sju_dagars_tabell     ← NY: senaste 7 dagar med PSI per dag
    avvikelseflaggor      ← NY: dagar som bryter mönstret (≥1.6σ)
    konvergens_idag       ← NY: varning om 3+ metriker kritiska samtidigt

  Output (JSON):
    modell_uppdatering.reviderade_fält  — mergas in i profiles.data
    agent_koordinering                   — koordinering mellan agenter
    systeminsikt:
      rubrik           — insiktens rubrik
      insikt           — huvudtext
      prediktion       — vad som händer härnäst
      rekommendation   — vad att göra
      prioritet        — "Hög" / "Normal" / "Låg"
      grundat_i        — datapunkter som stödjer
      mönster_referens ← NY: vilket mönster refereras
      psi_förklaring   ← NY: varför PSI är som det är

  Sparar: systeminsikt → insights (agent="meta")
  Sparar: reviderade_fält → profiles.data (merge)

──────────────────────────────────────────────────────
SCHEMA-AGENTEN (inline i server.js)
──────────────────────────────────────────────────────
  Trigger:   POST /api/agent/schedule/recommend
  Uppgift:   Anpassar dagens träning och kost efter PSI
  Input:     senaste 14 check-ins, träningsschema,
             kostprotokoll, profil
  max_tokens: 800

  PSI-regler:
    PSI < 55  → kör_planerat = false, modifiera alltid
    PSI 55-70 → kör_planerat = true, sänk intensitet 1-2
    PSI > 70  → kör_planerat = true, kör som planerat

  Kost-regler:
    fastar + PSI < 60 + tung träning → justera kolhydrater upp

  Output:
    träning:
      kör_planerat      boolean
      rekommendation    string (max 120 tecken)
      modifiering       string eller null
      intensitet_idag   number (1-10)
      fokus_idag        string
      varning           string eller null
    kost:
      följ_protokoll    boolean
      justering         string eller null
      prioritet_idag    string
      timing            string eller null
    systeminsikt        string (en mening)

11. CRON / SCHEMALAGDA KÖRNINGAR
═══════════════════════════════════════════════════════

Meta-agenten körs dagligen för alla aktiva användare
via POST /api/agent/meta/schedule (kräver SCHEDULE_SECRET).

Trigger kan sättas upp som:
  - Railway cron job
  - Extern scheduler (t.ex. cron-job.org)
  - node-cron lokalt (paketet finns installerat)

Logik: hämtar alla user_id som check-inat idag,
       kör runMetaAgent() för varje användare asynkront.
